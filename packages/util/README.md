# @hpcc-js/wasm-util

Shared utilities used across the `@hpcc-js/wasm-*` packages.

Public behavior is specified in [`../../specs/util/`](../../specs/util/) and exercised by
the acceptance tests in [`../../tests/acceptance/util/`](../../tests/acceptance/util/).
Run `npm run check-specs` and `npm run test-acceptance` from the repository root to validate
spec traceability and the shared Node/browser scenarios.
